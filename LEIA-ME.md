# Bruna Dantas — versão atual

O projeto React, TypeScript, Vite e GSAP está na raiz do repositório.

- `src/`: código, componentes, imagens e fontes.
- `public/`: arquivos públicos.
- `package.json`: scripts e dependências.
- `Bruna-Dantas-previa.html`: prévia autocontida.

```bash
npm ci
npm run dev
npm run typecheck
npm run build
```

A build gera `dist/`. No Vercel, selecione Vite, raiz do repositório (`./`), comando `npm run build` e saída `dist`.

A versão atual inclui a assinatura Camila Lopes Studio no rodapé e respeita automaticamente a preferência de movimento reduzido do sistema, sem botão de movimento na interface.

Consulte `README.md` para conteúdo, interações e privacidade.
